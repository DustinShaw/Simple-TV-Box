# Simple TV Box 1.1.3

## English

- Fix the video picture freezing on the last frame while audio kept playing
  after switching the preview player to fullscreen.
- Root cause: `enterFullscreen()` detached `playerFrame` from the view tree and
  re-attached it to the root `FrameLayout`. Because `PlayerView` defaults to
  `surface_type="surface_view"`, that destroyed the `SurfaceView` surface.
  ExoPlayer kept decoding audio, but its video renderer held a dead surface
  and never re-bound it.
- Fullscreen now keeps `PlayerView` attached: hide the details panel, status
  text and episode grid, clear the player padding and grow the video column's
  layout params to `MATCH_PARENT`. Exiting restores all of them symmetrically.
  The `SurfaceView` only goes through `surfaceChanged`, which is a safe path.
- No new permissions, dependencies or resources; a single Java file changed.

Android 5.0+; ARMv7 and ARM64 in one signed APK. Package ID and signing
certificate are unchanged, supporting in-place upgrades without clearing history.

## 简体中文

- 修复预览播放进入全屏后画面卡在最后一帧、声音继续播放的问题。
- 根因：`enterFullscreen()` 把 `playerFrame` 从视图树摘下再挂到根布局，
  默认 `surface_type="surface_view"` 的 SurfaceView surface 因此被销毁；
  ExoPlayer 继续解码音频，但视频渲染器持有的 surface 已失效且未重新绑定。
- 现在全屏不再移动 `PlayerView`：隐藏详情面板、状态文字与剧集列表，
  清除播放器内边距，并把视频列的 LayoutParams 放大到 `MATCH_PARENT`；
  退出时对称恢复。SurfaceView 只发生尺寸变化（surfaceChanged），属于安全路径。
- 未新增权限、依赖或资源，仅改动一个 Java 文件。

支持 Android 5.0+，同一个已签名 APK 包含 ARMv7 和 ARM64。
包名与签名保持不变，可覆盖安装，保留播放记录及搜索记录。

## Verification

- `:app:assembleDebug` and `:app:lintDebug` passed on JDK 17 + Android SDK 35
  (0 errors, 34 warnings, all pre-existing).
- Seven Java test suites and the 59 translation-key / placeholder checks passed.
- Wireless ADB test on an XSTV `xstv-658` TV box (Android 6.0 / API 23, ARMv7,
  1920x1080), A/B comparison with the same title and the same fullscreen action:
  - Pre-fix build: 61.9% of video pixels changed per second before fullscreen,
    **0.0% across four consecutive frames after fullscreen** (frozen frame),
    while `AudioTrack` stayed active and the SurfaceView reported
    `mGraphicBuffer is null`.
  - Fixed build: **96.8%–99.99% of video pixels changed per second** in
    fullscreen; three enter/exit cycles restored the details panel and episode
    grid each time; seek and Back keys worked; no crash or ANR.
- The on-device comparison used the debug APK. Rebuild and sign the release
  APK before publishing it.
